# Point-in-time S&P 500 weekly features

Place `sp500_weekly_features.csv` at `data/sp500_1950_2025/sp500_weekly_features.csv`. One row represents one stock (`permno`) at one weekly observation date. The required header is:

```text
date,permno,adjusted_ret,adjusted_close,adjusted_volume,adjusted_close_200sma,sp500_market_cap_rank
```

Fields:

| Field | Meaning and scale |
| --- | --- |
| `date` | ISO date, e.g. `1990-01-05`; weekly observation date. |
| `permno` | Stable numeric security identifier, not a present-day ticker symbol. |
| `adjusted_ret` | Weekly total return as a decimal, with dividends and split/delisting treatment chosen consistently. `0.01` means 1%. |
| `adjusted_close` | Weekly adjusted closing price, in a consistent adjustment convention. |
| `adjusted_volume` | Weekly adjusted trading volume; the pipeline sums weekly values within each month. |
| `adjusted_close_200sma` | 200-*trading-day* simple moving average of the adjusted close, computed from the underlying daily history before weekly sampling. Do not replace this with a 200-week or monthly average. |
| `sp500_market_cap_rank` | Point-in-time market-cap rank among S&P 500 constituents as known on that weekly date; lower is larger. Do not use a current-constituent list or a future rank. |

Supply enough pre-1990 history for the 60-month rolling lookback, the 12-month relative-volume moving average, and the precomputed 200-day price average. The study's source spans 1950–2025; the evaluated portfolios run January 1990–December 2025. Monthly returns are compounded from weekly `adjusted_ret` observations. The monthly rank is the last available weekly rank in the month, and the monthly close/200-day-SMA inputs use the last weekly values. RVOL is monthly adjusted volume divided by its trailing 12-month monthly mean. Missing signal values are filled with zero within the estimator, matching the original backtest. The point-in-time universe is the 30 smallest valid ranks among stocks with sufficient observed return history at each rebalance.

The baseline runner creates `data/sp500_1950_2025/sp500_weekly_panel/day_rets.csv` and `mon_rets.csv` automatically. Those are derived local files and are not committed. This input is not obtainable from the code alone; use a licensed point-in-time security/constituent data source and document any deviations from the original adjustments and ranking convention when interpreting differences from the paper.
