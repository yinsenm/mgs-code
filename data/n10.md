# 10-asset daily panel

Place `n10_daily.xlsx` directly in this directory. The SSRN study uses daily total-return index levels from December 1987 through December 2025. The exact asset columns, in order, are:

1. `SPX Index` — S&P 500;
2. `RTY Index` — Russell 2000;
3. `MXEA Index` — MSCI EAFE;
4. `MXEF Index` — MSCI Emerging Markets;
5. `LBUSTRUU Index` — Bloomberg U.S. Aggregate Bond;
6. `LF98TRUU Index` — Bloomberg U.S. Corporate High Yield Bond;
7. `FNERTR Index` — FTSE NAREIT All Equity REITs;
8. `SPGSCI Index` — S&P GSCI Commodity Index;
9. `XAU Curncy` — gold;
10. `NDX Index` — Nasdaq 100.

The original workbook has a Bloomberg-style layout: the date is in column A; row 4 (one-based) contains those ticker labels; row 7 onward contains daily dates and numeric price/index levels. Rows 1–3 and 5–6 contain metadata/field descriptions. The loader uses the first token of each row-4 ticker cell as its column name (`SPX`, `RTY`, and so on), interprets row 7 onward as data, sorts dates, and keeps the last observation on duplicate dates. Do not mix price-only and total-return series or splice differently adjusted histories if you want the published numbers.

The baseline backtest takes each week's last available daily close (Friday-anchored week), computes weekly percentage returns, and estimates covariance from the trailing 36 calendar months. MGS+Div computes weekly close divided by its trailing four-week simple moving average minus one. Portfolios are rebalanced monthly from January 1990 through December 2025, with early windows using available history since December 1987. No separate returns file is needed.

If you have a clean CSV instead, the loader also accepts `Date,SPX,RTY,MXEA,MXEF,LBUSTRUU,LF98TRUU,FNERTR,SPGSCI,XAU,NDX`; pass its path via `--data-path` to all three 10-asset runners and use the corresponding `--data-stem` when building tables. The default commands in the root README assume the Excel filename above.
